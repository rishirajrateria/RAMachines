# ADR-0007 — Photography layer: full-screen image banners and image slots

Owner feedback: "add boxes with dummy images where they fit; too much text; I prefer a full-screen intro
image banner at the start of each page (banner text is fine)". Real photos come later; every image slot
uses a generated placeholder now and is swappable by filename.

## 1. Page hero with image (`components/layout/PageHero.tsx`)
- Every page starts with a full-bleed image banner: home `min-height: 100svh`, all other pages
  `min-height: 78svh` (mobile 70svh). The image is `next/image` `priority` with `fill` + `object-cover`,
  explicit `sizes="100vw"`, and a soft scrim (`linear-gradient(180deg, rgba(246,248,249,.15), rgba(246,248,249,.55) 70%, #F6F8F9 100%)`)
  so the page fades into the canvas at the bottom.
- The existing glass panel (`.glass-strong`) sits over the image — home centred, inner pages bottom-left
  aligned — carrying breadcrumbs (tiny), eyebrow, H1 (unchanged text), one sentence, buttons and the
  page's 3 inline facts. Nothing else in the hero.
- Slow Ken Burns on the image (scale 1 → 1.06 over 18 s, alternate, reduced-motion: off). On the home
  page the HeroVideo remains as an optional overlay layer above the image at 35 % opacity (light drift).
- Props: `{ image: { src, alt }, size?: "full" | "tall", align?: "center" | "start", children }`.

## 2. Image slots (`components/ui/ImageSlot.tsx`, `ImageBand.tsx`)
- `ImageSlot` — a glass-framed image box (radius 28px, hairline, soft shadow) with `aspect` ("16/9" |
  "4/3" | "3/4" | "1/1"), `next/image` with explicit width/height, optional caption. While a slot uses a
  placeholder, a tiny bottom-left pill reads e.g. "Photo: factory floor" (`label` prop) — the label
  disappears when `placeholder` is false (i.e. once a real photo is dropped in).
- `ImageBand` — a full-bleed 16:9 → 21:9 image between sections with an optional short overlay line.
- Placement rules: at most one image per section; images alternate sides with text in two-column
  blocks; product pages show the glyph on the hero image and a 3-image gallery of photo slots.

## 3. Placeholder photo library (`public/photos/*.webp`, generated by `scripts/generate-photos.mjs`)
Photographic-feeling abstract placeholders (NOT cartoons, NOT plain grey): layered soft gradients in
graphite/teal/white, depth-of-field light bokeh, faint light streaks and grid perspective, subtle film
grain, and a small line-art silhouette (machine / hall / crate / person) at low opacity so each reads as
"a photo of X". Each 1920×1080 (heroes) or 1600×1200 (4:3 slots), WebP quality 78, ≤ 180 KB each.
Set (filenames fixed so pages can reference them):
hero-home, hero-products, hero-fiber, hero-tube, hero-co2, hero-welding, hero-product, hero-repair,
hero-training, hero-jobwork, hero-about, hero-contact, hero-certifications, hero-india, hero-state,
hero-city, hero-export, hero-country;
slot-factory, slot-assembly, slot-cutting-head, slot-sparks, slot-tube-cutting, slot-robot-weld,
slot-control-panel, slot-engineer-service, slot-training-room, slot-crate-shipping, slot-port,
slot-team, slot-office, slot-installation, slot-quality-check, slot-warehouse-spares.
Add a `photos` map in `lib/photos.ts` exporting typed `{ src, alt, width, height }` for each key.

## 4. Where images go (page workers)
- Home: PageHero(hero-home); ImageBand(slot-factory) after the fact strip; "Why" cards get image tops
  (slot-quality-check, slot-engineer-service, slot-installation); "Where we work" tiles get slot-port /
  slot-crate-shipping backgrounds at low opacity; testimonials strip unchanged.
- Products index: PageHero(hero-products). Category: PageHero(hero-<category>). Product: PageHero(hero-product)
  with the line-art glyph overlaid; gallery = 3 ImageSlots (slot-cutting-head, slot-sparks, slot-control-panel or
  category-appropriate).
- Repair: PageHero(hero-repair); ImageSlot(slot-engineer-service) beside the form; ImageBand(slot-warehouse-spares).
  Training: PageHero(hero-training); ImageSlot(slot-training-room). Job work: PageHero(hero-jobwork).
- About: PageHero(hero-about); ImageBand(slot-factory); two-column story with slot-assembly and slot-team;
  Contact: PageHero(hero-contact); ImageSlot(slot-office). Certifications: PageHero(hero-certifications).
- India hub: PageHero(hero-india). State: PageHero(hero-state) ; ImageSlot(slot-installation) beside the delivery steps.
  City: PageHero(hero-city); ImageSlot(slot-engineer-service). Export hub: PageHero(hero-export); ImageBand(slot-port).
  Country: PageHero(hero-country); ImageSlot(slot-crate-shipping) beside shipping prose.
- Text: heroes carry ≤ 40 words. Prose columns stay for SEO but every prose section pairs with an image slot.
